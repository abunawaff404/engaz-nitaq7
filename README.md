# منصة إنجاز — النطاق السابع

تطبيق ويب عربي لإسناد مهام المدارس السبع، تسجيل إنجاز المدير، مراجعة المشرف، ترتيب المدارس وتصدير CSV.

## التشغيل
1. ثبّت Node.js 20 أو أحدث.
2. افتح المجلد في الطرفية وشغّل `npm install`.
3. عيّن متغيرات البيئة التالية **على الخادم فقط** (لا تضعها في ملفات الموقع أو GitHub):
   - `ADMIN_NATIONAL_ID` رقم هوية المشرف من 10 أرقام.
   - `ADMIN_PASSWORD` كلمة مرور قوية من 12 حرفاً على الأقل.
   - `DATA_DIR` مجلد دائم قابل للكتابة، مثل `/var/data/engaz`.
   - `NODE_ENV=production` عند النشر عبر HTTPS.
4. شغّل `npm start` ثم افتح `http://localhost:3000` محلياً.
5. سجّل الدخول كمشرف، وأنشئ حساباً منفصلاً لكل مدير، ثم أسند المهام.

## النشر العام
يمكن نشر المشروع على خادم Node.js مع HTTPS ودعم قرص دائم، مثل VPS أو خدمة استضافة تدعم Persistent Disk. اضبط متغيرات البيئة، اربط القرص الدائم بمجلد DATA_DIR، ثم اضبط أمر التشغيل `npm start` والمنفذ عبر PORT. **لا تستخدم استضافة صفحات ثابتة مثل GitHub Pages لهذا الإصدار**: تسجيل الدخول وقاعدة البيانات يحتاجان خادماً.

## الأمان والخصوصية
- لا تُخزّن كلمات المرور نصاً صريحاً؛ تستخدم bcrypt، والجلسات محفوظة ببصمة SHA-256 في قاعدة البيانات، والكوكي HttpOnly.
- يستخدم رقم الهوية لتسجيل الدخول، ولا يظهر في قوائم المدارس والتقارير.
- يحتاج الإنتاج الفعلي إلى سياسة خصوصية وموافقة الجهة التعليمية قبل جمع أرقام الهوية والشواهد، وإلى نسخ احتياطية مشفرة دورية، ومراقبة وتحديثات أمنية، وإجراء لاستعادة كلمة المرور والتحقق من هوية المستفيد.
- أدخل شواهد بروابط أو أوصاف خالية من بيانات الطلاب الشخصية؛ النسخة الحالية لا تدعم رفع الملفات مباشرة.
- ينبغي تشغيله خلف HTTPS، وحماية إعدادات البيئة، وحصر صلاحية الوصول إلى النسخ الاحتياطية.

## حدود النسخة
- الترتيب يحسب الإنجاز التراكمي، وليس الأسبوعي بعد؛ لا يوجد بعد تصفية زمنية أو إرسال رسائل آلية أو PDF.
- يحتاج النشر على خدمة استضافة فعلية، ولم يتم نشره من هذه الحزمة.
- يمكن إضافة إدارة الحسابات (تعطيل/إعادة تعيين كلمة مرور) وسجل تدقيق قبل التوسع في الاستخدام.
